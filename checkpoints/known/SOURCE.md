# Known baseline source

`p196-org-verification.csv` is copied from this repo’s root `verification.csv`.

Upstream public table:

- https://www.p196.org/html/verification.html

Format:

```text
digit_count,iteration,first_25_digits
```

The original site notes these were cross-verified across independent machines/programs (Dec 2010 for the published table used here). One inconsistent 187,000,000-digit row is omitted — see comments at the top of the CSV.
